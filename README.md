# Мой кошелёк

Личные финансы на телефоне: доходы и расходы, категории с любой вложенностью (иконка и цвет настраиваются), лимит на месяц, постоянные операции, разбивка «Куда уходят деньги / Откуда деньги», светлая и тёмная тема.

Основная валюта — злотый (zł). Рядом с суммами можно показывать пересчёт в EUR, USD или UAH по курсу ПриватБанка (резерв — НБУ); курс можно ввести и вручную.

Это один файл `index.html` без сборки и без сервера. Все данные хранятся в браузере устройства (localStorage), никуда не отправляются.

## Открыть

https://<ваш-логин>.github.io/<имя-репозитория>/

На iPhone: Safari → «Поделиться» → «На экран «Домой»». На Android: меню Chrome → «Установить приложение».

## Данные

- Данные есть только на том устройстве и в том браузере, где вы вводили операции. На другом телефоне или в другом браузере приложение будет пустым.
- Резервная копия: меню ⋯ → «Сохранить копию в файл» (скачивается файл), восстановление: «Восстановить из копии». Делайте копию перед очисткой данных браузера.

## Обновление

Заменить `index.html` и запушить в `main`. GitHub Pages обновится за минуту.
